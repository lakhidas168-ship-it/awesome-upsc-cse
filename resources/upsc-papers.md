# Official UPSC papers — how to reach them

Download papers only from the Commission's own site. Exact PDF URLs change
every year, so navigate from the archive home page:

1. Open [Previous Question Papers](https://www.upsc.gov.in/examinations/previous-question-papers).
2. Select "Civil Services Examination".
3. Pick Prelims (General Studies-I, CSAT) or Mains (Essay, GS I–IV, Optional, Languages).

The yearly **notification** (with the syllabus annexure) is published on
[www.upsc.gov.in](https://www.upsc.gov.in/) under the examinations section.
Always read the current year's notification — pattern details change.

This repo never mirrors PDFs. Links only.
