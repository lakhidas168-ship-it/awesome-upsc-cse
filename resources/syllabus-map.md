# GS1–GS4 + Essay syllabus map (index only)

Paper names follow the official CSE notification. The full syllabus text for
each paper is the notification annexure on
[upsc.gov.in](https://www.upsc.gov.in/) — this file is only an index so you
know which paper a topic belongs to.

## Prelims

- **General Studies-I** — counts for merit (history, geography, polity,
  economy, environment, S&T, current affairs).
- **CSAT (General Studies-II)** — qualifying in nature.

## Mains

| Paper | Index |
|-------|-------|
| Essay | Two essays |
| GS-I | Heritage, culture, history, world + Indian geography, society |
| GS-II | Constitution, polity, governance, social justice, international relations |
| GS-III | Economy, technology, environment, security, disaster management |
| GS-IV | Ethics, integrity, aptitude |
| Optional I + II | One optional subject |
| Indian Language, English | Qualifying |

## Interview

Personality test after Mains. Details: current year's notification.

> No marks, attempts, or age limits are listed here — they change by
> notification and category. Read the official notification.
